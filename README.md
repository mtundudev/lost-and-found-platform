# MUST-lost-and-found

MUST Lost & Found

A full-stack web application designed to help university students report, search for, and recover lost or found items within the campus community.

📌 About the Project

MUST Lost & Found is a platform where students can report items they have lost or found on campus.

Instead of relying on WhatsApp groups or physical announcements, students can use the platform to:

- Report a lost item
- Report a found item
- Search for lost or found items
- View item details
- Contact the person who posted an item
- Mark an item as returned

The project is being developed as a real-world full-stack learning project.

🎯 Project Goals

The main goals of this project are to:

- Make reporting lost and found items easier
- Help students find their missing belongings
- Provide an organized platform for lost and found information
- Practice full-stack web development
- Learn how frontend, backend, and databases work together
